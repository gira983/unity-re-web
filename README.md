# Unity RE Web

Веб-верстак для разбора Unity-игр: закинул файл — получил структуру.
Работает в любом браузере, включая iPhone/iPad — без установки, без App Store.

**Зачем:** Il2CppDumper, UABEA, Il2CppInspector — отличные, но десктопные и неудобные.
Цель — те же возможности в браузере: перетащил `.ipa`/`.apk`/бандл — увидел классы, ассеты, строки.

## Roadmap

- **v0.1** ✅ распознавание файлов: UnityFS-бандлы (заголовок) + `global-metadata.dat` (версия)
- **v0.2** декомпрессия блоков (LZ4/LZMA/ZSTD) → список файлов внутри бандла
- **v0.3** дерево ассетов: TextAsset, Texture2D, AudioClip + выгрузка
- **v0.4** парсинг il2cpp-метаданных → дерево C#-классов (порт ядра Il2CppDumper в WASM)
- **v0.5** UI: поиск, xref, сохранение сессии в IndexedDB

## Запуск

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Для теста подойдёт любой Unity-бандл
(`*.bundle`, `*.unity3d`, `assets`) или `global-metadata.dat` из игры.

Инструмент — для исследования форматов, моддинга одиночных игр, разбора своих
сборок и учебных целей. Не для читерства в онлайн-играх и обхода DRM.
